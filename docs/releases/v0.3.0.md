# Ain v0.3.0 (experimental pre-release)

Ain is an experimental AI-oriented general-purpose language, with compact prefix syntax and an extensive built-in library.

### Highlights

- Native compiler CLI (`ainc`) with type inference, formatting, structured diagnostics, and Rust-backed code generation.
- Experimental typed AIR and LLVM backend for numeric and Boolean programs.
- Typed lists, maps, tuples, Option/Result, inferred parametric functions, and many standard-library operations.
- Native integrations for JSON/CSV/TOML, SQLite, HTTP, file and process operations, GTK4 desktop interfaces, and experimental media exporters.
- LLM coding benchmark supporting OpenAI-compatible Chat Completions APIs, with execution-based grading and reported token accounting.
- Automated compiler builds and smoke tests for five platforms.

### Download

Choose the matching `ainc-<platform>` archive under **Assets**, extract the binary, and run `ainc --version`.

| Platform | Archive |
| --- | --- |
| Linux x86-64 (static musl; works on NixOS) | `ainc-linux-x86_64.tar.gz` |
| Linux ARM64 (static musl) | `ainc-linux-aarch64.tar.gz` |
| macOS Apple Silicon | `ainc-macos-aarch64.tar.gz` |
| macOS Intel | `ainc-macos-x86_64.tar.gz` |
| Windows x86-64 | `ainc-windows-x86_64.zip` |

Each archive has a corresponding `.sha256` checksum file. The release binaries contain **the Ain compiler**, not a full cross-platform toolchain. To compile Ain programs with the native Rust backend you still need `rustc`. The experimental LLVM backend requires Clang. Generated GUI and other native applications may need system libraries.

**Pre-release limitations:** Ain is not production-ready. AIR/LLVM and the self-hosted compiler support smaller subsets than the Rust backend. Builtin capability checks do not isolate untrusted generated programs. See the documentation and CI tests for current support.
