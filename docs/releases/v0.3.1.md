# Babel v0.3.1 (experimental pre-release)

Babel is the new name of the Ain programming language. This release aligns the compiler, source paths, runtime, benchmarks, and downloadable artifacts with the new name.

## Migration from Ain

- Repository: `https://github.com/honerop/babel` (old GitHub links redirect).
- Compiler CLI and executable: `ainc` → `babelc`.
- Cargo package: `ain-compiler` → `babel-compiler`.
- Source extension: `.ain` → `.babel`; example and bootstrap files use the new extension.
- Runtime file and internal symbol prefixes: `ain_*` → `babel_*`.
- Capability environment variables: `AIN_PERMISSIONS` and `AIN_RESTRICTED` → `BABEL_PERMISSIONS` and `BABEL_RESTRICTED`.
- LLM benchmark language ID: `ain` → `babel`; its CLI now uses `--babelc`.

The experimental typed AIR and `air` compiler command keep their existing name for compatibility. The older v0.3.0 release still distributes `ainc`.

## Download

Each successful release build provides a SHA-256 checksum and one compiler archive per platform:

| Platform | Archive |
| --- | --- |
| Linux x86-64 (static musl, NixOS-compatible compiler executable) | `babelc-linux-x86_64.tar.gz` |
| Linux ARM64 | `babelc-linux-aarch64.tar.gz` |
| macOS Apple Silicon | `babelc-macos-aarch64.tar.gz` |
| macOS Intel | `babelc-macos-x86_64.tar.gz` |
| Windows x86-64 | `babelc-windows-x86_64.zip` |

Run `babelc --version` after extraction. Compiling Babel programs still requires external Rust or Clang tooling and may require native libraries.

**Experimental:** The compiler and runtimes are pre-alpha. Untrusted generated code is not sandboxed. The LLVM/AIR backend supports only a subset of Babel.
