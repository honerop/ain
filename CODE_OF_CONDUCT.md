# Code of conduct

We want BABEL discussions and contributions to be constructive.

Contributors and maintainers are expected to treat others respectfully, focus criticism on ideas and code, avoid harassment or discrimination, and respect privacy.

If a discussion becomes hostile or unsafe, maintainers may moderate it, close threads, or restrict participation. Report problems privately to the repository owner via GitHub, rather than escalating them in public threads.

This code of conduct applies to project issues, pull requests and project discussion spaces.
