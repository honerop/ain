# Security policy

## Project status

AIN is **pre-alpha research software** and does not provide a security sandbox. **No stable, security-supported releases are available.**

Generated code is native code. Do not compile or run untrusted AIN source in an unrestricted environment. The self-hosted C compiler and temporary-string runtime are experimental.

## Reporting vulnerabilities

If GitHub's **Private vulnerability reporting** feature is enabled for this repository, use the **Security** tab to submit a private report. Otherwise, contact the repository owner privately through their GitHub profile before publishing details.

Please include the affected revision, steps to reproduce, impact, and a minimal example that does not include secrets. Avoid opening a public issue with an exploit, tokens or private information.

There is no guaranteed response-time SLA for this experimental project.
